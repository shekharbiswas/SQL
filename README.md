## 🧩 The Challenge Ahead: Can Data Help TrendHive Compete?

**TrendHive** is a rising eCommerce brand selling viral products — from solar-powered gear to eco-friendly accessories. But now it’s scaling fast, and **data is the only way to survive**.

They’ve hired you as a **junior data analyst** to support product, marketing, and operations teams. But there’s a catch — each team comes with **messy questions, evolving goals, and incomplete information.**

You won’t be told what to do.  
Instead, each week starts with a **realistic business problem**.  
You’ll investigate, explore multiple paths, and present what *you* think is the best insight.

<br>

## 🧠 Week 1: Where Are We Selling the Most?

> 📦 *“Sales just started coming in — but we don’t know what’s actually selling well.”*

TrendHive has launched. Orders are flowing. But no one has a clear answer to:
- Which cities are performing best?
- What products are trending?
- What’s the average order size?

### 🔍 Your task:
Use basic SQL to analyze the `orders` and `products` datasets. Identify key patterns, then create a **Top Cities by Sales** report.

<details>
<summary>💡 Concepts You’ll Explore</summary>

- SQL foundations: SELECT, WHERE, ORDER BY  
- Filtering text, numbers, and dates  
- Querying TrendHive’s raw order data  
</details>

<details>
<summary>✅ By the End of Week 1</summary>

- Write basic queries  
- Filter and sort data  
- Build your first business insight: *Where should TrendHive focus next?*
</details>

<br>

## 🔗 Week 2: Who Are Our Best Customers?

> 👥 *“We’ve added a loyalty program. Can we track which customers are worth retaining?”*

Customer data is now available, along with support tickets. The **Customer Support team** wants help analyzing:
- Which customers are loyal?
- Who raises the most tickets?
- Are high-spending customers getting quick resolutions?

### 🔍 Your task:
Use joins and aggregates to uncover **top customers, churn risks, and support patterns**.

<details>
<summary>💡 Concepts You’ll Explore</summary>

- JOINs: customers + orders + tickets  
- Aggregates: SUM, COUNT, AVG  
- Handling NULLs and segmentation  
</details>

<details>
<summary>✅ By the End of Week 2</summary>

- Combine multiple tables  
- Segment customers by behavior  
- Build *Mart 1: `sales_summary`*
</details>

<br>

## 📈 Week 3: Are Our Marketing Campaigns Working?

> 📣 *“We’ve run 3 ad campaigns this month. Which one worked best?”*

The marketing team wants to know:
- Which campaign brought in buyers (not just clicks)?
- Which channel had the best ROI?
- How do we attribute success?

But the data isn’t clean — click doesn’t always mean purchase. You’ll need logic.

### 🔍 Your task:
Use advanced SQL to **attribute sales to campaigns**, and report which strategy paid off.

<details>
<summary>💡 Concepts You’ll Explore</summary>

- CTEs and subqueries  
- CASE WHEN for segmenting  
- Window functions for user behavior  
</details>

<details>
<summary>✅ By the End of Week 3</summary>

- Model attribution logic  
- Answer the question: *Where should we invest next?*
</details>

### 🔍 Your task:
Clean and explore `reviews` + `returns` data. Create a dashboard showing **quality insights and product-level pain points.**

<details>

Refactor your SQL into a DBT project, and deliver `fulfillment_analytics`.

</details>

# 📅 6-Week SQL Course Plan (Post-Power BI)

Welcome! This course helps you build strong SQL skills and introduces modern tools like DBT and Snowflake — without overwhelming you. It's designed to be hands-on, practical, and career-relevant.

<br>

## ✅ Week 1: SQL Foundations – Read & Query

**Goal:** Learn basic SQL syntax and how to extract data.

### Topics:
- What is SQL? What are relational databases?
- SELECT, FROM, WHERE
- ORDER BY, LIMIT, logical operators
- Filtering text, numbers, and dates

### Activities:
- Explore a “Sales & Customers” dataset
- Practice simple queries in a SQL sandbox

### Mini-task:
> Find the top 3 cities with the highest number of orders.

<br>


## ✅ Week 2: Joins, Aggregates & Grouping

**Goal:** Combine data and summarize information.

### Topics:
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- GROUP BY, COUNT, SUM, AVG
- HAVING vs WHERE
- Date functions and filtering

### Activities:
- Work with multi-table datasets (e.g., Orders + Customers)
- Identify missing matches and outliers

### Mini-project:
> Monthly sales report by region using JOIN + GROUP BY.

<br>

## ✅ Week 3: Subqueries, CTEs & Data Cleaning

**Goal:** Write modular queries and handle messy data.

### Topics:
- Subqueries in SELECT, WHERE, FROM
- Common Table Expressions (CTEs)
- NULL handling, COALESCE, CASE WHEN
- Data formatting and basic logic

### Mini-project:
> Identify inactive customers with low sales and high return rates.

<br>

## ✅ Week 4: Power BI + SQL Mini-Project (Light Week)

**Goal:** Connect SQL to Power BI and build a small report.

### Activities:
- Connect Power BI to a SQL source (sample DB or SQLite)
- Write 1–2 SQL queries (e.g., total sales by category, monthly trend)
- Build:
  - Bar chart: Top 5 categories
  - Line chart: Monthly sales
  - Optional slicer by region or year

### Deliverables:
- Power BI file (`.pbix`)
- Screenshot of dashboard
- 3-question reflection:
  1. What did you enjoy building?
  2. Where did SQL help the most?
  3. What would you improve next time?

> **Total time:** ~8 hours max

<br>

## ✅ Week 5: DBT & Data Warehousing Basics

**Goal:** Learn modern data transformation & modeling.

### Topics:
- What is DBT? Why it's used in analytics
- DBT concepts: models, sources, staging, marts
- DAG (directed acyclic graph) and lineage
- Introduction to Data Warehouses
- Snowflake (demo or screenshots)

### Activities:
- Hands-on with DBT Cloud (optional)
- Build one staging + one transformation model

<br>

## ✅ Week 6: Final Capstone Project + Career Wrap-Up

**Goal:** Apply everything in a real-world scenario.

### Capstone:
> Build a small analytics pipeline using:
- SQL to extract and clean customer-product data
- DBT to transform and document
- Power BI to visualize key trends

### Deliverables:
- Clean SQL scripts
- DBT model and DAG screenshot
- Power BI dashboard
- Short project report

### Wrap-Up:
- GitHub portfolio setup
- Career tracks in Data Analytics
- Final Q&A and certification of completion
