# 📅 6-Week SQL Course Plan (Post-Power BI)

Welcome! This course helps you build strong SQL skills and introduces modern tools like DBT and Snowflake — without overwhelming you. It's designed to be hands-on, practical, and career-relevant.

---

## ✅ Week 1: SQL Foundations – Read & Query

**Goal:** Learn basic SQL syntax and how to extract data.

### Topics:
- What is SQL? What are relational databases?
- SELECT, FROM, WHERE
- ORDER BY, LIMIT, logical operators
- Filtering text, numbers, and dates

### Activities:
- Explore a “Sales & Customers” dataset
- Practice simple queries in a SQL sandbox

### Mini-task:
> Find the top 3 cities with the highest number of orders.

---

## ✅ Week 2: Joins, Aggregates & Grouping

**Goal:** Combine data and summarize information.

### Topics:
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- GROUP BY, COUNT, SUM, AVG
- HAVING vs WHERE
- Date functions and filtering

### Activities:
- Work with multi-table datasets (e.g., Orders + Customers)
- Identify missing matches and outliers

### Mini-project:
> Monthly sales report by region using JOIN + GROUP BY.

---

## ✅ Week 3: Subqueries, CTEs & Data Cleaning

**Goal:** Write modular queries and handle messy data.

### Topics:
- Subqueries in SELECT, WHERE, FROM
- Common Table Expressions (CTEs)
- NULL handling, COALESCE, CASE WHEN
- Data formatting and basic logic

### Mini-project:
> Identify inactive customers with low sales and high return rates.

---

## ✅ Week 4: Power BI + SQL Mini-Project (Light Week)

**Goal:** Connect SQL to Power BI and build a small report.

### Activities:
- Connect Power BI to a SQL source (sample DB or SQLite)
- Write 1–2 SQL queries (e.g., total sales by category, monthly trend)
- Build:
  - Bar chart: Top 5 categories
  - Line chart: Monthly sales
  - Optional slicer by region or year

### Deliverables:
- Power BI file (`.pbix`)
- Screenshot of dashboard
- 3-question reflection:
  1. What did you enjoy building?
  2. Where did SQL help the most?
  3. What would you improve next time?

> **Total time:** ~8 hours max

---

## ✅ Week 5: DBT & Data Warehousing Basics

**Goal:** Learn modern data transformation & modeling.

### Topics:
- What is DBT? Why it's used in analytics
- DBT concepts: models, sources, staging, marts
- DAG (directed acyclic graph) and lineage
- Introduction to Data Warehouses
- Snowflake (demo or screenshots)

### Activities:
- Hands-on with DBT Cloud (optional)
- Build one staging + one transformation model

---

## ✅ Week 6: Final Capstone Project + Career Wrap-Up

**Goal:** Apply everything in a real-world scenario.

### Capstone:
> Build a small analytics pipeline using:
- SQL to extract and clean customer-product data
- DBT to transform and document
- Power BI to visualize key trends

### Deliverables:
- Clean SQL scripts
- DBT model and DAG screenshot
- Power BI dashboard
- Short project report

### Wrap-Up:
- GitHub portfolio setup
- Career tracks in Data Analytics
- Final Q&A and certification of completion
